# RICOS SID Uploads

Dedicated public storage repository for SID files published through **RICOS MOD – JAMES SIDPLAYER ONLINE** (TEST84).

## Purpose

- Store redistributable `.sid` assets separately from the player source code.
- File paths are generated by the Cloudflare Worker: `sid/<sha256>.sid`.
- Collection metadata and track order live in Cloudflare D1, not this repository.
- Publishing is restricted by server-side beta-key authentication; users do not need GitHub access.

## Status

Repository initialized. **Uploads are not enabled yet.** Cloudflare Worker deployment, GitHub token configuration, and D1 schema setup must be completed and tested before first publication.

## Safety

Only upload SID files that you have rights to redistribute. Never commit GitHub access tokens, beta keys, or other secrets here.
